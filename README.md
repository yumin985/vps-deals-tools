# VPS Deals Tools

Reusable, source-first resources for checking VPS offers against the provider's public source page.

The companion site is [vpsdealsscout.com](https://vpsdealsscout.com/). It publishes source URLs and fetch timestamps; it does not replace the provider's current terms.

## Contents

- `data/vps-offers.csv` — a compact snapshot of public records used by the site.
- `docs/verification-checklist.md` — a field-by-field checklist for auditing a VPS offer.
- `tools/normalize_offers.py` — a standard-library-only converter for `offers.json`.

Prices, availability, renewal terms, and eligibility can change. Recheck each official source before ordering.
