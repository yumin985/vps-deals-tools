# VPS offer verification checklist

Use the provider's official public page as the source of truth. Save the URL and UTC check time with each record.

1. Match the exact plan name, region, currency, and billing period.
2. Record the displayed price exactly as published; do not derive a renewal price from a discount percentage.
3. Look for explicit recurring, renewal, or after-the-initial-term wording. If absent, record renewal as unknown.
4. Record any validity date, availability limit, or eligibility requirement.
5. Keep the source URL and fetched-at timestamp with the record.
6. Reopen the provider page at checkout because prices, terms, and availability can change.

The public tracker using this checklist is [vpsdealsscout.com](https://vpsdealsscout.com/).
